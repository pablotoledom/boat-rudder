Browser detection

%2$s

Which epoch each visitor's browser gets, and which browsers may use the dashboard. Rules are checked top to bottom; the first one whose contains has a token found in the User-Agent (and whose excludes has none) decides. Tokens are case-sensitive and matched as plain text. If the rule reads a version, the highest tier that version reaches gives the epoch; otherwise the rule's own epoch applies. Raise the epoch 3 tiers when the public stylesheet starts using newer CSS.
